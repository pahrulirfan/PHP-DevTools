Support PIPanel

PIPanel is free for everyone, for personal and commercial work, and it stays that way. If it saves you time, a donation helps keep it tested and maintained on Linux, Windows and macOS.

Where it goes

What a donation pays for

PIPanel is built and maintained by one developer. Donations buy time for the work that keeps it reliable.

Testing on real machines

Checking each release on Linux Mint and Ubuntu, Windows and macOS, beyond what the automated tests on GitHub can cover.

Fixes and new PHP versions

Answering bug reports, following new PHP, MySQL and MariaDB releases, and keeping the downloads working when upstream sites change.

What comes next

Features on the list, such as PostgreSQL, and code-signed packages so Windows and macOS stop warning about an unknown developer.

A donation is a thank-you, not a purchase: it does not unlock features or buy support. Every feature of PIPanel is in the free download.

No money needed

Other ways to help

  • Star the repository on GitHub, so other developers find it.
  • Report a bug or suggest a feature. Reports from Windows and macOS desktops are especially welcome.
  • Tell a colleague, your class or your team about PIPanel.
  • Improve the code or the documentation with a pull request; see Development.
