About

Who makes PIPanel

A local PHP development app for Linux, Windows and macOS, made at Universitas Mataram by a lecturer and researcher in Informatics.

The author

Pahrul Irfan

Lecturer and researcher in Informatics at the Faculty of Engineering, Universitas Mataram (Unram), Lombok, Indonesia.

Pahrul Irfan designed PIPanel, decides what goes into it, and uses it every day on Linux Mint. Questions, bug reports and ideas are welcome on GitHub.

How it is built

Written with the help of Claude

Much of PIPanel's code, tests and documentation was written with Claude, the AI assistant made by Anthropic, using its Opus model in Claude Code.

The author decides

Which features PIPanel has, how it should behave, and what is good enough to release are decided by Pahrul Irfan, who reviews the changes and tries them on real machines.

Claude writes the code

Claude (Opus) wrote much of the code, the tests and these pages from those decisions, and worked through the failures found on Linux, Windows and macOS.

Tests check both

More than 400 automated tests, and scripts that start the real Nginx, PHP and databases, run on GitHub for all three systems on every change, so nothing is taken on trust.

The project

Free and open source

PIPanel is free for personal and commercial work. The source, the design notes (PLAN.md) and every release are on GitHub. The interface uses the Inter font, under the SIL Open Font License.

If PIPanel saves you time, you can support it with a donation.
